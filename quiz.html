快速开始

  • 双击 exe 后会自动打开浏览器；不需要额外安装环境，也不需要手动配置题库。
  • 首次进入输入一个用户ID即可创建本地账号，后续会自动记住该用户。
  • 选择课程，再选择速刷、答题或错题回顾模式即可开始学习。

学习模式

  • 速刷模式会直接展示答案，适合考前快速过题。
  • 答题模式会记录答题统计，答错的题会进入对应课程的错题本。
  • 错题回顾会从错题本中抽题复习，也可以手动删除已经掌握的错题。

键盘操作

  • 答题时按 A B C D E 选择或取消选项。
  • 按 Enter 提交当前题；答案显示后再按一次可进入下一题。
  • 按 ← 回到上一题，按 → 进入下一题或查看总结。
  • 正在输入用户ID或跳转题号时，快捷键不会触发。

AI 题库服务

  • 导入题库（粘贴 JSON）适合配合网页端 AI 使用：让 AI 输出 clean_outputs 兼容 JSON，然后直接粘贴导入。
  • AI API 导入题库使用 OpenAI 兼容接口，可以填写 API Base URL、API 路径和模型；默认路径是 /chat/completions。
  • 两种导入方式都可以新建自定义题库，也可以导入到已有自定义题库的新章节，例如“自定义题库1”的“新一章选择题”。
  • API Key 只用于本机请求，不会写进题库文件，也不会展示在页面日志里。
